# Photo Gallery

Hello World! Welcome to the **Photo Gallery** project.

A modern, responsive, and interactive photo gallery website built using HTML5, CSS3, and JavaScript.

## 🌐 Live Demo
GitHub Pages URL: [https://liteshraomupparti-byte.github.io/Photogallery/](https://liteshraomupparti-byte.github.io/Photogallery/)

## 🚀 Features
- **Responsive Layout:** Adaptive grid for desktop, tablet, and mobile devices.
- **Dynamic Filtering:** Filter photos by categories (Nature, Architecture, Travel, Wildlife).
- **Interactive Lightbox:** Click on any photo to open a high-resolution modal view with captions.
- **Modern UI Design:** Dark theme with smooth animations, hover effects, and Google Fonts.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla ES6)
- GitHub Pages
